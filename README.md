# Codeforces Solutions

My personal collection of solutions for [Codeforces](https://codeforces.com) competitive programming problems, written in **C++**.

[Codeforces Profile](https://codeforces.com/profile/Fallen-Reader)
## Language

- **C++17 / C++20** (GNU++17 compiler)


Each file is named after the problem code (e.g., `Problem-1A.cpp`, `Problem-2A.cpp`) or the problem title for standalone solutions.

## How to Compile & Run

```bash
# Compile
g++ -std=c++17 -O2 -Wall -Wextra -Wshadow -DLOCAL -o main Problem-1A.cpp

# Run
./main < input.txt
```
Or directly:
```bash
g++ Problem-1A.cpp -o Problem-1A
```
